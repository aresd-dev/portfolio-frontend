## Projetos

**Diário de Bordo — otimização de performance**
PWA para registrar atividades diárias, em HTML, CSS e JavaScript puro. Documenta um processo de otimização validado com Lighthouse: Total Blocking Time reduzido em 88%, mantendo nota 100 em todas as categorias.
https://github.com/aresd-dev/frontend-performance

**Sistema de Pedidos com Micro Frontends**
Três apps Next.js independentes (container, cardápio e pedido), integradas em tempo de execução com Webpack Module Federation, comunicando por eventos do navegador.
https://github.com/aresd-dev/frontend-microfrontends

**Lista de Tarefas**
Next.js (App Router) com TypeScript, testes com Jest e Testing Library, e CI/CD no GitHub Actions com deploy automático no Vercel.
https://github.com/aresd-dev/lista-tarefas
Demo: https://lista-tarefas-bnalwz612-ares-projects-8460dcad.vercel.app
